# 当前回执与受管完成

## ReceiptV1

绑定输入和基线的绝对路径、真实路径、字节数、SHA-256；阈值；上游根、契约摘要和八个执行依赖文件哈希；插件版本及回执明确列出的运行文件哈希；Node版本、Python版本／真实路径／解释器字节哈希、pandas版本／发行METADATA哈希。稳定JSON摘要绑定整个范围，再绑定report、stdout、stderr字节。

回执以同目录临时文件和排他创建发布，不覆盖旧回执。未执行门禁、范围变化、环境无法核实或写入失败不能生成可复用回执。status不补造或修复。

这是一份本地完整性记录，不是签名或外部时间戳，不抵御能重写整个状态根的用户。未哈希整个Node安装、Python标准库、pandas全部代码或操作系统；覆盖清单以回执为准，不宣称检测清单外变化。

## GateStatusV1

`historical_verdict`是已存结果，`current_verdict`是本次可采用结论。`freshness`为FRESH／STALE／UNKNOWN，`integrity`为VALID／INVALID／UNKNOWN。完整回执与当前范围一致才沿用历史三态；缺失、损坏或不能确认时当前为REVIEW／null。

常见原因包括输入／基线变化、策略变化、执行器变化、插件变化、环境变化、回执损坏和输出不符，实际reason_codes以返回为准。不靠mtime判内容，保留mtime的字节变化也需重放。

查询只接受UUID，读取有大小限制，拒绝越界运行目录或重定向；baseline UUID必须来自本状态根的有效回执。来源核对不是语义核查。检查有时间窗口，不提供文件锁或持续监控。

## 受管任务

会话来源为宿主agent.session.id。bind不执行门禁；允许绑定完整当前FAIL／REVIEW记录待处理任务，complete必须两次复验当前PASS，范围与本会话绑定一致，且完成记录落盘成功。未绑定、跨会话、重启、范围变化、重复／并发完成或写入失败均拒绝。

这是受管入口条件校验，不控制其他完成路径或外部权限。completionMode默认off；remind借停止事件提醒已绑定未完成任务，按会话／轮次／任务及范围去重，取消或上限触达后不继续提醒。它不保证模型服从，不构成普通聊天全局阻断。

卸载释放工具、事件、HTTP路由和内存绑定；保存的证据不自动删除。完成记录不会恢复绑定授权。

## 0.3.0 辅助入口

doctor 的 READY／环境就绪与门禁 PASS 分开，异常或提醒返回 REVIEW。它只做环境核验与临时写入探针，不生成回执。list 只读扫描，逐条复用 status；损坏、缺失记录另列，不能省略后称全部有效。

batch 顺序复用 replay，每份独立留痕；有已确认 FAIL 则总体 FAIL，无 FAIL 但有 REVIEW、错误、取消或未处理项则 REVIEW。错误属于执行分类，计数与质量失败分开。输入数组与单层目录二选一，最多 200 份，不递归；目录或参数错误发生在执行前则不重放任何份。

export 只在状态根 exports 追加唯一文件名。先验证所有目标的回执和原输出，任一损坏不部分导出；不要求当前仍为 PASS，旧回执可以导出但必须解释当前状态。Markdown 同列当前有效性与历史裁决；单条 JSON 保留原回执字节，多条 JSON 是原回执对象数组。JSON 内容不增加当前状态，工具返回的 current 单独列出本次复验。升级插件会使旧回执的插件绑定变化，旧结果保留但须重新重放才能取得当前可复用资格。

## 卡片与本地路由

浏览器模块用真实tool.call.toolview槽，会话关联由宿主结果metadata生成。/veriscope/status只接受同源、回环连接及已关联的session／run，只能查状态，不能执行replay／complete。宿主应仅监听受信本地接口，这不是多租户授权系统。

挂载和点击时重新检查；初始、加载、断连或协议异常均为待复核。请求序号和取消防止旧响应覆盖新状态。卡片只代表所示检查时刻，不持续刷新。无Web槽或无会话关联时保留中文工具文本。
