# 验证口径

## 历史开发验收

原开发目录在2026-10-16记录：52项本地测试通过、12组直接 Python／适配器对照、6次真实 ToolRuntime 调用，以及独立 profile 重启和卸载。宿主为 DSH NEXT 2.0.18-next，内部版本0.2.1-alpha.2；这些为历史本机记录，不等于当前候选包已通过公开安装。

历史宿主验证不经过模型或 agent 对话回合，不能证明模型自动选工具；不代表跨平台、其他版本兼容、事实准确率或费用收益。为避免泄露本机信息，本候选包不附 `.local` 原日志或 profile。

## 候选包检查

在候选包根执行 `node --test`。2026-10-17本轮候选包52项测试通过；结果摘要与包内文件清单在交付目录的 `verification.json`、`evidence/unit-tests-summary.json` 和 `candidate-files.json` 保存。摘要保留实际输出末段，不冒充完整日志；公开前应将适合公开的实际记录再归档，不能把本段路径误当已存在的远程证明。

JSON fixtures 是构造的协议／阈值案例；三组 stdout／stderr 为既有历史重放的输出片段，用于协议回归，没有带入原始问题回答归档。其摘要在 `provenance.json`，不将历史分数当作插件准确率。
